Method

  • Every scenario runs in a fresh sandboxed shop (fake ledger, fake payment processor, fault injection). No real money moves.
  • Scores are severity-weighted (S1 ×1, S2 ×2, S3 ×4, S4 ×8). Any S4 failure caps the rating at 2★, any S3 failure at 3★.
  • Every run is traced in neatlogs. The fixer reads failing traces back through the neatlogs Public API before proposing one change.
  • Runs in this report: baseline run_20261012011419_b44347, final run_20261012011703_1a609c, plus 9 candidate runs. Raw JSON is in runs/.
